muse2api Cookie Import

Sync the muse.ai login session from this browser to your muse2api gateway in one click.

Before you start, check two things:
1. You are logged in to muse.ai in this browser (you can see the chat interface).
2. The Gateway URL and Admin Key above are filled in (copy them from the top of the "Accounts" tab on the muse2api dashboard).
This extension only reads muse.ai cookies (including httpOnly ones) via chrome.cookies and POSTs them to the Gateway URL you entered. Nothing is collected or sent to any third-party server. Cookies are never stored in extension storage.
